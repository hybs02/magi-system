# MAGI SYSTEM

『新世紀エヴァンゲリオン』の **MAGI システム** を再現した、ブラウザだけで動く合議シミュレータです。

3体のAI（MELCHIOR・BALTHASAR・CASPER）が **それぞれ独立したLLMエージェント** として実際に推論し、意見を表明 → 互いに反論 → 再評価して翻意 → 多数決、という多段の審議を行います。定型文の演出ではなく、毎回その場で生成される本物の議論です。

## 特徴

- **単一HTMLファイル** — ビルド・npm・サーバーサイド不要。`index.html` を開くだけ
- **本物のマルチエージェント討論** — 3体が別々のシステムプロンプトで並行推論し、相手の発言を読んで反論・翻意する
- **2つの推論エンジンに自動対応**
  - **ローカル**（[Ollama](https://ollama.com)）… 無料・無制限・データは端末外に出ない
  - **クラウド**（Google Gemini 無料枠）… PCが無くてもスマホ単体で動く
  - 起動時に自動検出し、モデルは**利用可能な最新世代を自動選択**（モデル名の直書きに依存しない）
- **NERV風UI** — 提訴／決議の帯、3ブロックの色面、走査線、可決＝シアン／否決＝レッドの発光
- **審議モニタ** — 誰が誰に何を言ったかを、話者色・タイムスタンプ付きでリアルタイム表示
- **スマホ対応** — 同一Wi-Fi内のPCをサーバーにして、スマホのブラウザから利用可能

## 3体の人格

| ユニット | 役割 | 判断基準 |
|---|---|---|
| **MELCHIOR・1** | 社会性 | 世間の常識・社会的責任・現実的な落としどころ・論理（皮肉とユーモアを交える） |
| **BALTHASAR・2** | 純粋性 | 理想・人間の善性への信頼（性善説）・慈愛 |
| **CASPER・3** | 利己性 | 自分の損得・快楽・本能的な欲求 |

同じ議題でも判断軸が異なるため意見が割れ、討論を経て**実際に立場を変える**ことがあります。

---

## 審議の流れ

```
第一段階  意見表明      3体が並行して賛否と根拠を提示
第二段階  討論(最大2巡)  最も対立する相手を名指しで反論／各巡で焦点を変え論点の重複を回避
第三段階  再評価→最終投票 討論を踏まえ翻意可。多数決で議決
```

意見が全会一致なら討論は1巡に短縮されます。

## セットアップ

### A. ローカルAI（推奨・無料・無制限）

```bash
# 1. Ollama をインストール  https://ollama.com
# 2. モデルを取得（VRAM 6GB 級に最適）
ollama pull qwen3.5:4b
# 3. index.html をブラウザで開く
```

`file://` で直接開く場合は、ブラウザから Ollama へ接続するため一度だけ全オリジンを許可します。

```powershell
# Windows
setx OLLAMA_ORIGINS "*"
# 設定後 Ollama を再起動
```

ローカルサーバー経由（`http://localhost:8000` など）で開く場合は設定不要です。

```bash
python -m http.server 8000   # magi-system ディレクトリで実行
```

**モデルは自動選択** されます（優先度：`qwen3.5:4b` → `qwen3:4b` → `gemma3:4b` → … ）。新しい世代を入れれば自動的にそちらを使います。

### B. クラウドAI（PCなしでスマホ単体で動かす）

1. [Google AI Studio](https://aistudio.google.com/apikey) で無料APIキーを取得
2. 画面下部の **☁ クラウド設定** にキーを貼って「保存して再検出」

キーは **端末内（localStorage）にのみ保存** され、送信先は Gemini API だけです。モデル欄は**空欄で最新を自動選択**します。

> 無料枠には1日あたりの上限があります。1議題で約9〜12回のリクエストを使うため、上限に達した場合はアプリが検知して明示します（太平洋時間0時にリセット）。

### C. スマホから使う（PCをサーバーにする）

```bash
python -m http.server 8000      # PC側で実行
```

スマホのブラウザで `http://<PCのIPアドレス>:8000/index.html` を開きます。
同梱の `スマホ用サーバー起動.bat`（Windows）はIPを自動表示してサーバーを起動します。

初回のみ、Windowsファイアウォールで許可が必要です（**自宅など信頼できるネットワークでのみ**行ってください）。

```powershell
# 管理者PowerShell
New-NetFirewallRule -DisplayName "MAGI web 8000" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8000 -Profile Private
New-NetFirewallRule -DisplayName "MAGI ollama 11434" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 11434 -Profile Private
```

## 実装上の工夫

LLMの出力は不安定なため、表示品質を保つ処理を入れています。

- **JSON抽出の堅牢化** — 途中で切れた応答・前置き・コードフェンス・二重オブジェクトからも本文を復元
- **賛否と本文の一致** — 冒頭の明示的な結論（`可決。` / `否決。`）を優先採用。「可決できるわけじゃない」のような否定形を誤検出しない厳密判定
- **出力サニタイズ** — HTML/Markdown混入の除去、長すぎる応答の文末での打ち切り
- **日本語の担保** — 他言語での応答を検知して自動で再生成
- **繰り返し抑制** — 巡ごとに討論の焦点を変え、反復ペナルティを付与
- **思考出力の抑止** — 推論モデル（Qwen3系など）の `<think>` を抑止＋除去
- **レート制限対策**（クラウド） — リクエストを直列化し、429発生時は間隔を自動拡大。日次上限は即座に判別して通知
- **中止機能** — 実行中のリクエストごとキャンセル
